# Critique of the earlier PILLA poster

The AI-generated poster misread the theory. Each error is marked ❌.

❌ **1 — "Layer" misread.** Shown as software / OSI strata. In PILLA the layers are
recursive *geometric* layers on one boundary; patient / doctor / machine are audiences
at different magnifications, not stacked channels.

❌ **2 — Information floating in space.** Poster: information → layer → machine.
PILLA: geometry *is* the information; it lives on faces, not beside them.

❌ **3 — Colour as decoration.** Colour is a parametric encoding dimension attached to
named faces (top = drug class, floor = dose, walls = timing).

❌ **4 — Grooves nearly absent.** Grooves are the central mechanism, G = (Γ, L, R, S),
not a minor feature.

❌ **5 — Face algebra gone.** No top/bottom/rim, no bevel/chamfer/groove/facet,
no gross-vs-net face creation.

❌ **6 — Recursion drawn as exploded disks.** It should be a zoom (map-like), not
separated components.

❌ **7 — Mathematical hierarchy missing.** topology → geometry → features → recursion →
encoding → manufacturing → observation → decoding.

❌ **8 — Geometry demoted.** Everything looks like software; geometry must be primary —
it survives wetting, wear and crushing.

❌ **9 — Human/machine as parallel channels.** They are one geometry at different
resolutions.

❌ **10 — No pitch / capacity.** N_s ≈ A/p², I ≈ N_s·log₂M absent — capacity never
quantified.

❌ **11 — No feature grammar.** alphabet → words → sentences (tablets) → language
(manufacturing).

❌ **12 — Logo not explained.** The mark shows the tablet writing, but never what it
writes (onto its own surface).

❌ **13 — Information not on faces.** Floating labels instead of colour/geometry
instantiated on named faces.

❌ **14 — Electronic / software confusion.** The root error: "information layering" read
as microservices / OSI. It is recursive geometric layering.

❌ **15 — No mathematical centrepiece.** I = f(A, p, Φ, R, M, O) should dominate the
visual.

**Got right:** the tablet-writing metaphor, colour as a dimension, multiple audiences,
creative logo use — a good entry point, wrong development.
